## 一句话背景

路径 A 裁决把关系分类器钉死在"LLM 五选一"，且写明"若 LLM 分类器未达预先登记的验收门槛，
则协议尚不具备冻结条件；不得临时改用 NLI"。**裁决封死了"静默降级"，但没写"不达标之后
怎么办"**。本备忘补上退路——把"不达标"预设为一种**正常结局**，而非事故。

## 关键认知（先读）

- **误差方向性比准确率更重要**：50 对标注不是测"准不准"一个数。真正影响主测量（分歧集 D）
  的是误差**是否有方向**——若误判对 P/F 两套策略对称，在 D 里互相抵消，不影响结论；
  若偏向某类（如 contradict 常被误判成 duplicate → 系统性压低 persistence 的 EV），
  才是 v4 §2.2 已登记的"有方向失效模式"。
- **"实验不启动"是比"结果不理想"更坏的结局**：卡在原地连反驳的机会都没有。

## 三个出口（按概率排列）

### 出口 A（最可能）：分类器"勉强可用"——看混淆矩阵方向性

- 触发条件：50 对准确率约 70–80%，或准确率尚可但某类召回偏低。
- 动作：
  1. 用校准期缓存（`cache/pairs.jsonl`）算**混淆矩阵**（尤其 duplicate↔contradict 双向、
     mergeable 漏判率）；
  2. 误差均匀/对称 → **冻结**，把误差率写进预登记作为已知仪器边界；
  3. 误差有方向 → 评估该方向是否威胁 D 主测量；若威胁，回到出口 B 的换 prompt 重校准。
- 工具：`tools/export_annotation_pairs.py` 已能导出 50 对；校准后补一个混淆矩阵统计即可。

### 出口 B：分类器系统性不行（准确率≈随机或频繁 B7 硬失败）

- 触发条件：准确率接近随机，或解析失败率导致运行不可完成。
- 动作：**正式走协议变更**，不偷着改：
  1. 按 v4 §0 声明"新方案改变了哪个可观测量、什么结果构成反驳"；
  2. 选项（按成本升序）：改分类 prompt 措辞重校准 → 换同族不同型号驱动 LLM →
     换不同家族驱动 LLM（缓存自动失效，成本最高）；
  3. 或整版降级为**机制 pilot**（先例：v0.1 的 Phase 3 先导实验——GLM 审查后降级，
     结论收窄为"机制方向符合描述、稳定性未测量"，仍是有价值的诚实结果）。
- 封死的是"静默降级"，不是"正大光明换方案"。
