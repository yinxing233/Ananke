## 1. 这版做什么（一句话）

把 persistence/frequency 对照从 v0.1 的"机制分歧 pilot"升级为**可证伪的严谨比较**：用关系分类器取代余弦阈值判信号，引入 LoCoMo session 语义定义 EV/IA，在分歧集 D 上测量 evidence 命中率，配评估独立性与预登记。

检验的命题 = 工程推论 C2"存续驱动迁移优于频率驱动"（主张层级链见 [v4 §1](../docs/01_PROTOCOL_v4.md)，不可越级到原则B/理论本身）。

## 2. 与旧 v0.2 的战略差异（重要）

| 维度 | 旧 v0.2（已废弃） | v0.2 = 协议 v4 |
|---|---|---|
| 死结解法 | 方向三：dedup 命中→改路由 reorg（仍在余弦轴上） | 召回-分类两段式：dedup/reorg 不再共余弦轴，死结自然解除（v4 §2.4） |
| 中→慢双策略切换 | 是（核心目标） | **否**——分歧改由分歧集 D 在整体升层集合上测（v4 §6），不切换第二道闸规则 |
| EV 污染（矛盾计为验证） | 未处理（先存泄漏） | 分类器区分 duplicate/contradict 解决（v4 §2.3） |
| 语料 | 手工 corpus_phase2.txt | LoCoMo（跨 session，v4 §3） |
| 统计 | n=1 零推断 | 分歧集 \|D\|≥20 功效下限 + 欠功效 sweep 预案（v4 §6） |
| 评估 | 同 LLM | 评估独立性：不同家族 LLM 主裁判（v4 §5） |
| 预登记 | 无 | [`../docs/RESEARCH_CONJECTURES.md`](../docs/RESEARCH_CONJECTURES.md)（v4 §7） |

> ⚠️ **需 PI 确认的战略点**：v4 放弃了"在中→慢这道闸上切换策略"的思路（旧 v0.2 的核心论点是"最稳定层最该显现分歧"）。v4 改为在整体升层集合的分歧集上测 evidence 命中率——这是更直接的 C2 检验，但**不再单独隔离第二道闸的贡献**。若 PI 认为"第二道闸可切换"仍是必须验证的命题，须在 v4 冻结前补回（见 §5 待澄清）。

## 3. v4 解决的问题

1. **v3 死结**（REORG⊂DEDUP 拦截区）：分类器取代余弦阈值，重组信号不再经过 dedup 丢弃堆（v4 §2.4）。
2. **EV 污染**（矛盾计为验证）：五分类 {duplicate, contradict, mergeable, related, unrelated} 区分"再确认"与"矛盾"（v4 §2.3）。
3. **EV/IA 的外部性定义**：session 边界 = 去相关事件；跨 session duplicate = EV，同 session related = IA（v4 §3）。
4. **统计严谨**：分歧集 D + evidence 命中率 + \|D\|≥20 功效下限 + 欠功效 sweep 预案（v4 §6）。
5. **评估独立性**：驱动端（embedding + Gemini 提取）与评判端（不同家族 LLM 主裁判）分离，嵌入模型禁出现在评估端（v4 §5）。
6. **预登记 + 探索/验证分离**：RESEARCH_CONJECTURES.md 冻结后成承诺；验证集须冒烟未接触的对话（v4 §7）。

## 4. v4 未做 / deferred

- **中→慢双策略切换**：未采用（见 §2）。若需，归待澄清。
- **闭环 / 世界演化**：v4 §3.3 明确 deferred 为 v0.3 方向（静态语料回放，系统是被动观察者，agent 输出不影响后续输入；闭环情形的原则B未检验）。
- **中文嵌入标定 / 多基准（LongMemEval-S）**：留 v0.4。
- **反事实重要性 / 被动衰减 / Reply 闭环 / Memory Identity 协议化**：留 v0.5+。
- **contradict 与 mergeable 的 trigger 是否分流**：v4 §2.3 把 contradict→"conflict trigger（进入重组流程）"、mergeable→local_reorganization_trigger +1，二者关系未完全定义——冒烟校准时须澄清（关联"core 该装被确认的还是被争议的"问题）。
