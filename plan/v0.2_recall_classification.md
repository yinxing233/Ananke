## 1. 这版做什么（一句话）

把 persistence/frequency 对照从 v0.1 的"机制分歧 pilot"升级为**可证伪的完整制度比较**：
用关系分类器取代余弦阈值判信号，引入 distinct-session EV，在第一道闸分歧集 D 上测量
reference-grounded evidence 命中率，配评估独立性与正式预登记。

检验的命题 = 工程推论 C2"存续驱动迁移优于频率驱动"（主张层级链见 [v4 §1](../docs/01_PROTOCOL_v4.md)，不可越级到原则B/理论本身）。

## 2. 与旧 v0.2 的战略差异（重要）

| 维度 | 旧 v0.2（已废弃） | v0.2 = 协议 v4 |
|---|---|---|
| 死结解法 | 方向三：dedup 命中→改路由 reorg（仍在余弦轴上） | 召回-分类两段式：dedup/reorg 不再共余弦轴，死结自然解除（v4 §2.4） |
| 中→慢双策略切换 | 是（核心目标） | **否**——分歧改由分歧集 D 在整体升层集合上测（v4 §6），不切换第二道闸规则 |
| EV 污染（矛盾计为验证） | 未处理（先存泄漏） | 分类器区分 duplicate/contradict 解决（v4 §2.3） |
| 语料 | 手工 corpus_phase2.txt | LoCoMo（跨 session，v4 §3） |
| 统计 | n=1 零推断 | 分歧集 \|D\|≥20 功效下限 + 欠功效 sweep 预案（v4 §6） |
| 评估 | 同 LLM | 评估独立性：不同家族 LLM 主裁判（v4 §5） |
| 预登记 | 无 | 探索推测来自 [`RESEARCH_CONJECTURES.md`](../docs/RESEARCH_CONJECTURES.md)；正式冻结时新建一次性 `PREREGISTRATION.md` |

> **PI 已确认的战略点**：v4 不在中→慢闸切换策略，D 只测 working→consolidated 第一道闸；
> P/F 被表述为两套完整选择制度，差异会经晋升、容量淘汰和后续召回传播。本实验不宣称
> 隔离计分函数或第二道闸的单因子贡献。

## 3. v4 解决的问题

1. **v3 死结**（REORG⊂DEDUP 拦截区）：分类器取代余弦阈值，重组信号不再经过 dedup 丢弃堆（v4 §2.4）。
2. **EV 污染**（矛盾计为验证）：五分类 {duplicate, contradict, mergeable, related, unrelated} 区分"再确认"与"矛盾"（v4 §2.3）。
3. **EV/IA 的外部性定义**：session 边界 = 去相关事件；每个后续 distinct session 对同一记忆至多贡献 1 次 EV（v4 §3）。
4. **CORE 可见性**：CORE 参与 top-1 召回分类但不进入任何 v0.2 晋升、淘汰、降级或裁决（B3）。
5. **统计严谨**：分歧集 D + reference-grounded evidence 命中率 + \|D\|≥20 功效下限 + 欠功效 sweep 预案（v4 §6）。
6. **评估独立性**：驱动端与不同家族 judge 分离；judge 同时接收 question + reference_fact，失败率>5% 时评估无效（v4 §5）。
7. **预登记 + 探索/验证分离**：探索推测保留原状，验证前新建一次性 `PREREGISTRATION.md`；验证集须使用冒烟未接触的对话（v4 §7）。

## 4. v4 未做 / deferred

- **中→慢双策略切换**：未采用（见 §2）。若需，归待澄清。
- **闭环 / 世界演化**：v4 §3.3 明确 deferred 为 v0.3 方向（静态语料回放，系统是被动观察者，agent 输出不影响后续输入；闭环情形的原则B未检验）。
- **中文嵌入标定 / 多基准（LongMemEval-S）**：留 v0.4。
- **反事实重要性 / 被动衰减 / Reply 闭环 / Memory Identity 协议化**：留 v0.5+。
- **CORE 增量吸收与矛盾裁决**：v0.2 只识别、计数、链接和完整留痕；mergeable 真合并、
  contradict 裁决/降级及“低变化率但吸收真增量”的慢层更新机制留给 v0.3。
